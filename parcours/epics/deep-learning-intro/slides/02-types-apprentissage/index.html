Les types d'apprentissage

Supervisé, non-supervisé, par renforcement : trois philosophies pour apprendre à partir de données.

Comment une machine peut-elle apprendre ? Il existe plusieurs stratégies, chacune adaptée à un type de problème. Comprendre ces approches vous aidera à choisir la bonne méthode pour vos projets.

Apprentissage Supervisé

L'apprentissage supervisé est le plus intuitif : on donne à la machine des exemples étiquetés (input + réponse attendue), et elle apprend à généraliser pour prédire sur de nouvelles données.

Données + Labels → Modèle prédictif

🏷️ Classification

Prédire une catégorie parmi un ensemble fini.

  • • Spam ou pas spam — Filtrage d'emails
  • • Chat, chien, oiseau — Reconnaissance d'images
  • • Positif, négatif, neutre — Analyse de sentiment
  • • Tumeur bénigne/maligne — Diagnostic médical

📈 Régression

Prédire une valeur continue (un nombre).

  • • Prix d'un appartement — Immobilier
  • • Température demain — Météo
  • • Chiffre d'affaires — Prévision business
  • • Durée de vie — Maintenance prédictive

Vocabulaire clé

Label — La réponse attendue (étiquette)

Feature — Une caractéristique de l'entrée

Train set — Données pour entraîner le modèle

Test set — Données pour évaluer le modèle

C'est le type que nous explorons en détail dans ce parcours. La majorité des applications de Deep Learning (vision, NLP, prédiction) utilisent l'apprentissage supervisé.

🔍

Apprentissage Non-Supervisé

Ici, pas de labels. La machine explore les données pour y découvrir des structures cachées, des groupes naturels, ou des anomalies. C'est une forme d'exploration de données.

Données brutes → Patterns & Clusters

Clustering

Regrouper des données similaires.

  • • Segmentation clients
  • • Groupes de documents
  • • Profils utilisateurs

Réduction

Compresser les données.

  • • PCA, t-SNE, UMAP
  • • Visualisation
  • • Compression

Anomalies

Trouver les points atypiques.

  • • Détection de fraude
  • • Pannes machines
  • • Intrusions réseau
🛒

Exemple : Segmentation e-commerce

Un site e-commerce analyse le comportement de ses clients (achats, navigation, panier moyen) sans labels prédéfinis. L'algorithme découvre naturellement 5 segments : "chasseurs de promos", "acheteurs premium", "visiteurs occasionnels", etc. Ces insights guident la stratégie marketing.

🎮

Apprentissage par Renforcement

Un agent interagit avec un environnement et apprend par essai-erreur. Chaque action génère une récompense (positive ou négative). L'objectif : maximiser les récompenses sur le long terme.

🤖
Agent
action → ← état, récompense
🌍
Environnement

Vocabulaire clé

  • Agent — L'entité qui apprend et agit
  • État — La situation actuelle
  • Action — Ce que l'agent peut faire
  • Reward — Signal de récompense (+/-)
  • Policy — Stratégie état → action

Applications célèbres

  • AlphaGo — Victoire contre Lee Sedol (2016)
  • OpenAI Five — Dota 2 contre pros
  • AlphaStar — StarCraft II niveau Grand Master
  • Robotique — Manipulation, locomotion
  • Trading — Stratégies d'investissement
🚴

Analogie : Apprendre à faire du vélo

Pas de manuel, pas de professeur qui donne les réponses. Juste des essais, des chutes (récompense négative), et progressivement l'intuition de l'équilibre (récompense positive). C'est exactement ainsi que fonctionne l'apprentissage par renforcement.

⭐

Bonus : Auto-Supervisé

L'apprentissage auto-supervisé est une approche hybride révolutionnaire : le modèle crée ses propres labels à partir des données brutes. C'est ce qui a permis l'explosion des grands modèles de langage.

Prédiction du mot suivant

Utilisé par GPT, LLaMA, Claude...

"Le chat dort sur le ___"
→ Prédire : "canapé", "lit", "tapis"...

Masquage de mots

Utilisé par BERT, RoBERTa...

"Le [MASK] dort sur le canapé"
→ Prédire : "chat"

Pourquoi c'est révolutionnaire ? Plus besoin d'annoter des millions de textes manuellement. Internet devient un dataset d'entraînement quasi-infini. C'est ce qui a permis d'entraîner GPT-4 sur des trillions de tokens.
