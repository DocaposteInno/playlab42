Ce qui distingue le Deep Learning

Réseaux profonds

Plusieurs couches cachées qui transforment progressivement les données en représentations abstraites.

Features automatiques

Le réseau découvre seul les caractéristiques pertinentes (pas de feature engineering manuel).

Big Data

Nécessite beaucoup de données (10K à millions d'exemples) pour bien généraliser.

Puissance GPU

Les calculs massifs sont accélérés par des processeurs graphiques (GPU/TPU).

Pourquoi le Deep Learning explose maintenant ?

📲 Big Data : internet, IoT, réseaux sociaux
⚙️ GPUs : calcul parallèle abordable
📚 Frameworks : TensorFlow, PyTorch

L'inversion du paradigme

La différence fondamentale entre la programmation classique et le Machine Learning tient en une phrase : qui écrit les règles ?

Programmation Classique

Règles + Données → Résultat

Vous écrivez explicitement les règles. L'ordinateur les applique.

if (oreilles_pointues && moustaches)
  return "chat";

Machine Learning

Données + Résultats → Règles

L'algorithme découvre les règles à partir d'exemples.

model = train(10000_photos_chat)
model.predict(nouvelle_photo)

Le processus d'apprentissage

Un réseau de neurones apprend comme un élève qui fait un exercice, vérifie sa réponse, puis corrige ses erreurs. Ce cycle se répète des milliers de fois :

➡️

1. Forward Pass

Calculer une prédiction à partir de l'entrée

📏

2. Mesurer l'Erreur

Comparer la prédiction à la vraie réponse

⬅️

3. Backprop

Propager l'erreur pour corriger les poids

La rétropropagation

C'est le mécanisme qui permet au réseau de savoir comment corriger chaque partie de son raisonnement. Nous l'explorerons en détail dans les slides suivants.
